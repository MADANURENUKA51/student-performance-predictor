# Student Performance Predictor

A simple Python project that predicts student performance based on study hours, attendance percentage, and previous marks.

## Technologies Used
- Python

## Features
- Takes student details as input
- Calculates a performance score
- Predicts Good Performance or Needs Improvement

## How It Works
1. Enter study hours per day.
2. Enter attendance percentage.
3. Enter previous marks.
4. The program calculates a score.
5. It displays the predicted result.
